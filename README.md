# Overview

As a software engineer, I am strengthening my foundation in Object-Oriented Programming (OOP), Kotlin fundamentals, and practical data management in a modern JVM language. Building an application like this helps me apply core engineering concepts such as encapsulation, state handling, and user-friendly input validation in a clean and maintainable design.

This project is a lightweight, console-based Task Management System created to help users organize and track daily responsibilities. The application supports full CRUD functionality, including creating tasks with titles, descriptions, and priority levels, viewing the task list with completion markers, updating existing tasks, marking items complete, and deleting tasks that are no longer needed.

The goal of this project is to gain hands-on experience structuring Kotlin applications using classes, collections, and interactive console logic. It demonstrates:

- Encapsulating task data in a dedicated `Task` class using private properties, getters/setters-style accessors, and custom string formatting.
- Managing dynamic groups of objects using Kotlin collections such as `MutableList`.
- Building a resilient CLI menu loop with input validation and exception handling to reduce runtime failures caused by invalid user entries.
